# 🌡️ Thermos – Temperature Converter

A modern and user-friendly temperature converter application built with **Flutter**. Thermos makes temperature conversion simple with a clean interface, smooth animations, and an intuitive user experience.

## ✨ Features

- 🌡️ **Temperature Conversion** – Convert between Celsius and Fahrenheit.
- 🔄 **Swap Units** – Quickly switch between conversion units.
- ⚡ **Instant Conversion** – Get accurate conversion results.
- 📋 **Copy Result** – Copy converted temperatures easily.
- 🎨 **Modern UI** – Clean, minimal, and responsive interface.
- 🎬 **Animated Splash Screen** – Attractive splash screen with custom app logo.
- 🚀 **Quick Temperature Presets** – Quickly select predefined temperature values.
- ✅ **Input Validation** – Handles empty and invalid inputs.
- 🧹 **Reset Functionality** – Clear input and conversion results easily.
- 📱 **Cross-Platform** – Built with Flutter for multiple platforms.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Amirhossainlimon/temperature_converter.git
```

### 2. Navigate to the Project Directory

```bash
cd temperature_converter
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

```bash
flutter run
```

## 🌐 Build for Web

To create a production-ready web build:

```bash
flutter build web --release
```

The generated web files will be available inside:

```text
build/web/
```

## 🧮 Conversion Formulas

Thermos uses the standard mathematical formulas for temperature conversion.

**Celsius to Fahrenheit:**

```text
°F = (°C × 9/5) + 32
```

**Fahrenheit to Celsius:**

```text
°C = (°F - 32) × 5/9
```
